# СЮЖЕТ — прототип сервиса вертикальных мини-сериалов

Рабочий прототип продукта: сайт, каким его видит зритель. Сделан, чтобы показать
механику формата вживую — свайпы, автопереход между сериями, клиффхэнгеры —
вместо того, чтобы объяснять её словами в деке.

**Название «СЮЖЕТ» — заглушка.** Меняется в одном месте:
`data/content.json` → `service.name`.

## Пароль

Сайт открывается парольным экраном. Пароль — **`654321`**.

Он не сверяется со строкой в коде: весь каталог (названия, синопсисы, все сорок
хуков, структура) лежит в репозитории зашифрованным — `data/content.enc`,
PBKDF2-SHA256 на 200 000 итераций плюс AES-256-GCM. Пароль служит ключом
расшифровки, поэтому обойти экран, поправив JavaScript, не выйдет: расшифровать
будет нечем.

Сменить пароль:

```bash
node scripts/pack.mjs новый-пароль
```

**Чего пароль не закрывает.** Видеофайлы лежат в репозитории обычными файлами и
доступны по прямым адресам — статический хостинг не умеет проверять доступ к
файлам. Закрыто то, что действительно наше: авторский текст и структура. Видео
чужое, и защитить его в публичном репозитории нечем.

Пароль держится в `sessionStorage` — перезагрузка во время показа не спросит его
заново, а после закрытия вкладки он не останется.

Расшифровка работает только в защищённом контексте (`https` или `localhost`).
По обычному `http` в локальной сети браузер не даст доступ к WebCrypto, и вход
не сработает — это не про пароль.

## Как открыть

Сайт читает `data/content.enc`, поэтому двойным кликом по `index.html` он не
заработает — нужен веб-сервер:

```bash
python -m http.server 8123
```

Дальше `http://localhost:8123`. Чтобы открыть с телефона — тот же адрес, но с
IP компьютера в локальной сети (`http://192.168.x.x:8123`), телефон и компьютер
в одном вай-фае.

Оговорка про этот сервер: `http.server` не отвечает на Range-запросы, поэтому
браузер тянет каждый ролик целиком и не умеет перематывать внутри ещё не
скачанного фрагмента. На воспроизведение и автопереход это не влияет — они
перемоткой не пользуются, — но для показа лучше выложить прототип на обычный
статический хостинг, где Range поддерживается.

## Витрина

Устроена так же, как у ReelShort и DramaBox: **каталог и есть главная
страница**. Ни у того, ни у другого нет блоков «о сервисе», преимуществ и FAQ —
только контент. У ReelShort это `New Release` → `TOP` → `Featured Series`,
у DramaBox `Must-sees` → `Trending` → `Hidden Gems`.

Здесь: рубрики-чипы по тропам, затем три ряда — «Смотрят сейчас», «Новинки»,
«По подписке». Выбранная рубрика переключает ряды на плоскую сетку.

Рубрики названы по жанровой грамматике категории. У конкурентов это
`Billionaire`, `Flash Marriage`, `Hidden Identity`, `Rebirth Revenge`,
`Contract Lover`, `Son-in-Law`, `CEO` — у нас Контрактный брак, Реванш, Дворец,
Скрытая личность, Босс, Семья, Перерождение.

**Из семнадцати сериалов видео есть у четырёх.** Остальные тринадцать —
заглушки: название, жанр, синопсис, объём сезона, замок. Видео для них не
скачивалось намеренно — они показывают каталог целиком и его платную часть.
Сезон у них 42–78 серий, как у настоящих тайтлов категории.

**Сюжеты заглушек русские, а не переводные.** Стройка под Москвой, вахта под
Новым Уренгоем, общежитие, сельмаг в райцентре, санаторий, дом в Кимрах,
приёмный покой, автосервис у метро, завод девяностых, школа в Тайшете, поезд
Москва — Владивосток, гостиница у вокзала, фиктивный брак ради ординатуры.
Это прямая иллюстрация к аргументу дека: у ShortTV перевод с китайского,
у нас — русские реалии. На витрине это видно рядом: четыре сериала на
заимствованных азиатских кадрах и тринадцать со своими историями.

### Обложки заглушек — сгенерированы

Брать чужие кадры под собственные русские сюжеты бессмысленно, а ключа ни к
одному платному генератору в системе нет. Поэтому обложки генерируются через
сервис, работающий по обычному URL без регистрации:

```bash
node scripts/make_covers_ai.mjs          # чего не хватает
node scripts/make_covers_ai.mjs --force  # перерисовать всё
node scripts/make_covers_ai.mjs p04 p09  # только указанные
```

Промпт под каждый сюжет лежит в самом скрипте, сид выводится из `id` — повторный
запуск даёт тот же кадр. Результат нормализуется под 720×1176, тот же размер,
что у обложек сериалов с видео, так что на витрине они неотличимы.

Людей держим на среднем плане или силуэтом: лица у бесплатных моделей выходят
неровно, а фактурная пустая сцена для постера драмы работает не хуже. В промпт
добавлено требование не рисовать текст — надписи модели даются плохо.

Заодно это иллюстрация к самому кейсу: обложки не сняты, а сгенерированы.

## Монетизация

Первые **8 серий бесплатны**, дальше экран разблокировки. Порог взят из
жанровой нормы: у DramaBox и Short Shot бесплатны первые десять, у типовых
сборок три, у ReelShort около шести за просмотр рекламы в сутки. Меняется
одним числом — `service.monetization.freeEpisodes` в каталоге.

Три варианта на экране, и порядок здесь не случаен:

1. **Посмотреть рекламу** — основная кнопка. Базовая модель бесплатная,
   с рекламной выручкой; реклама открывает одну серию
2. **Открыть все серии — 149 ₽** — платная альтернатива
3. **Оплатить со счёта телефона** — там, где у конкурентов обходные схемы
   сторов, это в один тап

Реклама — мок с обратным отсчётом: показывает петлю целиком, но ролика в
прототипе нет. Оплата ничего не проводит, о чём написано прямо на экране.

Разблокировка запоминается: реклама открывает одну серию, оплата — весь
каталог. Состояние живёт в `localStorage` рядом с прогрессом просмотра.

**Это демонстрация намерения, а не плана на завтра.** По деку 90-дневный тест
идёт без монетизации вообще — экран показывает, как сервис будет зарабатывать
на втором цикле.

## Механика

**Свайп вверх и вниз — серии внутри сериала.** Серия доигрывает до конца и
следующая стартует сама, без действия зрителя: именно на этом держится метрика
досмотра 1→10. За три секунды до конца поверх видео всплывает клиффхэнгер.
Справа — точки прогресса по сериалу. Тап по экрану ставит на паузу.

**Свайп влево и вправо — переключение сериалов.** Открывается карточка сериала:
постер, жанр, о чём история, кнопка. Через три секунды бездействия карточка
уезжает сама и серия стартует; нажатие запускает сразу. Если сериал уже
начинали, кнопка предлагает продолжить с той серии, где остановились.

**Сериал открывается со своей карточки, а не сразу с первой серии.** Иначе суть
истории не показывается нигде: из витрины зритель попадал прямо в середину
действия. При входе из витрины карточка держится пять секунд — описание
успевают прочитать, — при листании вбок трёх достаточно.

**У закрытых сериалов карточка такая же.** Раньше они выбрасывали прямо на
экран оплаты, минуя описание, — то есть предлагали заплатить за историю, о
которой зритель ничего не узнал. Теперь обложка, жанр, синопсис и полоска
серий у них те же, что у остальных, а платность обозначена на самой карточке:
метка «По подписке» у жанра, замок на кнопке, замки в полоске серий и строка
про порог бесплатных. Кнопка ведёт на разблокировку, карточка остаётся под ней.

Отсчёта до автостарта у закрытых нет: запускать нечего, а открывать оплату
самой по себе — навязчиво. Карточка ждёт действия зрителя.

Свайп вбок идёт по всему каталогу, включая закрытые: ленты им никто не строит,
показывается только карточка.

При первом открытии плеера на две секунды показывается подсказка про обе оси.
Горизонтальный свайп неочевиден, и без подсказки половина механики остаётся
ненайденной. Подсказка живёт только в памяти вкладки — каждое свежее открытие
сайта показывает её заново, чтобы телефон, на котором прототип уже гоняли при
подготовке, не показал ленту «немой».

На десктопе те же оси работают стрелками клавиатуры, пробел — пауза.

## Оффлайн

После первой загрузки service worker утаскивает всё видео в кэш, и дальше сайт
работает без сети. Это не украшение: показ идёт с телефона в переговорке, где
вай-фай может лечь, а переиграть демонстрацию нельзя.

**Перед показом:** открыть сайт заранее, дождаться в консоли
`Оффлайн-кэш готов: 40/40`, дальше можно включать авиарежим и проверять.

Service worker поднимается только на `https` или `localhost` — по `http` в
локальной сети он не зарегистрируется, и это нормально: останется обычная
загрузка по сети.

Стратегии кэширования разные, и это не придирка:

| Что | Как | Почему |
|---|---|---|
| Оболочка (html/css/js/каталог) | network-first | правки кода всегда доезжают |
| Видео | cache-first | десятки мегабайт, за жизнь прототипа не меняется |
| Обложки | stale-while-revalidate | перерисовываются на каждой итерации под тем же именем |

Обложки поначалу были cache-first, как и видео, — и застревали навсегда:
имя файла прежнее, кэш отдаёт старую картинку, обычная перезагрузка её не
пробивает. Теперь кэш отдаётся сразу, а свежая версия тихо подтягивается
следом и ложится на место: на следующем открытии будет новая.

### Если всё-таки закэшировалось

```
https://<адрес сайта>/?reset
```

Снимает service worker, чистит все кэши и хранилище, после чего сам
перезагружается на чистый адрес. Нужен потому, что на телефоне инструментов
разработчика нет, а иначе вычистить кэш нечем. Пароль после сброса
спрашивается заново.

Быстрая альтернатива — открыть сайт в режиме инкогнито: там ни кэша,
ни service worker'а.

Прогрев тянет около 90 МБ. При включённой экономии трафика или на 2G он
не запускается.

## Контент

Четыре сериала по десять серий. Набор повторяет логику теста из дека:
две романтики, анимация и сказочное.

| Сериал | Жанр |
|---|---|
| Расписались в день знакомства | романтика, золушка и CEO |
| Её уволили в пятницу | романтика, реванш |
| Котята для императора | историческое фэнтези |
| Зять, которого стыдились | драма, скрытый наследник |

**Тексты пересказывают сюжеты самих роликов.** Сначала под них были написаны
оригинальные русские истории — и это было ошибкой: зритель читал одно, а
смотрел совсем другое. Теперь названия, синопсисы и все сорок клиффхэнгеров
следуют настоящим сюжетам исходников, вплоть до имён и деталей: холодный
дворец и котята, десятилетний уговор с отцом и работа курьером, увольнение
в пятницу и совет директоров в понедельник.

Набор задумывался под жанровую логику теста из дека — две романтики,
манджу-анимация и сказочное. Вертикальной анимации в открытом доступе найти
не удалось: всё, что находится по запросам про маньхуа и донхуа, оказывается
либо горизонтальным, либо живыми актёрами. Поэтому третий сериал —
историческое фэнтези, а четвёртый — современная драма.

**Видео — чужое.** Это фрагменты сторонних вертикальных сериалов из открытых
источников, взятые как референс, чтобы показать механику формата. Своего
материала на момент сборки нет, права не приобретались, коммерческого
использования не предполагается. Идентификаторы исходников записаны в каталоге
(`source.id` у каждого сериала). В разметке стоит `noindex`, чтобы прототип не
попадал в поиск.

Как только появится собственный материал, чужой заменяется подменой файлов
в `media/s1..s4/`.

Четвёртый сериал изначально был задуман русской деревенской сказкой
(«Терем на семи ветрах»), но под этот слот нашлась только мистика в восточном
антураже. Постер режется из того же видео, так что несовпадение текста и
картинки бросалось бы в глаза — сюжет переписан под доступный материал,
жанровый слот сохранён.

**Когда появятся ролики Алехина**, они встают на место фрагментов подменой
файлов в `media/s1..s4/` — код трогать не нужно.

## Устройство

Ни одного внешнего ресурса: ни шрифтов, ни библиотек, ни CDN. Иначе оффлайн
не имел бы смысла.

```
index.html            вход, витрина, плеер и разблокировка в одной странице
css/style.css
js/app.js             вход, витрина, рубрики, состояние, оффлайн
js/player.js          обе оси навигации, автопереход, карточка сериала
js/paywall.js         порог бесплатных серий, экран разблокировки, мок рекламы
data/content.enc      весь контент, зашифрованный паролем
data/content.json     он же открытым текстом — только локально, в .gitignore
sw.js                 оффлайн-кэш
media/posters/        кадры-обложки четырёх сериалов с видео
media/covers/         сгенерированные обложки заглушек
media/s1..s4/         фрагменты серий
scripts/make_covers_ai.mjs генерирует обложки заглушек по промптам
scripts/pack.mjs          шифрует каталог перед публикацией
scripts/unpack.mjs        восстанавливает плейнтекст после клонирования
scripts/fetch_media.py    добывает и режет видео
scripts/check_media.py    проверяет комплектность перед показом
scripts/find_vertical.py  ищет вертикальные сериалы на YouTube
```

После свежего клонирования, чтобы править контент:

```bash
node scripts/unpack.mjs 654321        # получить data/content.json
# ...правки...
node scripts/pack.mjs 654321          # обратно в data/content.enc
```

**Всё содержимое — в `content.json`,** плеер рендерится из него. Количество
сериалов и серий нигде не зашито: добавить пятый сериал или урезать сезон до
шести серий — правка данных, а не кода. Этот же каркас переносится в боевую
версию.

### Почему нет IntersectionObserver и requestAnimationFrame

Обе вещи напрашивались — активная серия через `IntersectionObserver`, отсчёт
превью через `requestAnimationFrame`. Обе выкинуты: они работают внутри цикла
отрисовки и молча замолкают, когда вкладка не рисует кадры. При сборке это
поймалось — лента переставала переключать серии, а превью зависало навсегда.

Сейчас активная серия считается по позиции скролла (со `scroll-snap` она
кратна высоте панели — это точный расчёт), событие `scroll` работает основным
путём, а редкий таймер подстраховывает. Отсчёт превью — `setTimeout`, полоска —
CSS-переход. Плавный скролл после запроса проверяется: если лента не тронулась
за 420 мс, доводится жёстко.

Правило простое: механика показа не должна зависеть от того, рисует ли браузер
кадры прямо сейчас.

## Подготовка видео

```bash
pip install yt-dlp imageio-ffmpeg
python scripts/fetch_media.py           # всё, чего не хватает
python scripts/fetch_media.py s3 s4     # только указанные сериалы
```

Скрипт качает каждый фрагмент отдельным коротким отрезком с тремя попытками:
на длинных отрезках соединение рвётся, и обрыв не должен уносить весь сериал.
Готовые файлы пропускаются, так что запускать можно повторно — недостающее
дотянется.
