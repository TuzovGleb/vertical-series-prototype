# СЮЖЕТ — прототип сервиса вертикальных мини-сериалов

Рабочий прототип продукта: сайт, каким его видит зритель. Сделан, чтобы показать
механику формата вживую — свайпы, автопереход между сериями, клиффхэнгеры —
вместо того, чтобы объяснять её словами в деке.

**Название «СЮЖЕТ» — заглушка.** Меняется в одном месте:
`data/content.json` → `service.name`.

## Пароль

Сайт открывается парольным экраном. Пароль по умолчанию — **`sujet2026`**.

Он не сверяется со строкой в коде: весь каталог (названия, синопсисы, все сорок
хуков, структура) лежит в репозитории зашифрованным — `data/content.enc`,
PBKDF2-SHA256 на 200 000 итераций плюс AES-256-GCM. Пароль служит ключом
расшифровки, поэтому обойти экран, поправив JavaScript, не выйдет: расшифровать
будет нечем.

Сменить пароль:

```bash
node scripts/pack.mjs новый-пароль
```

**Чего пароль не закрывает.** Видеофайлы лежат в репозитории обычными файлами и
доступны по прямым адресам — статический хостинг не умеет проверять доступ к
файлам. Закрыто то, что действительно наше: авторский текст и структура. Видео
чужое, и защитить его в публичном репозитории нечем.

Пароль держится в `sessionStorage` — перезагрузка во время показа не спросит его
заново, а после закрытия вкладки он не останется.

Расшифровка работает только в защищённом контексте (`https` или `localhost`).
По обычному `http` в локальной сети браузер не даст доступ к WebCrypto, и вход
не сработает — это не про пароль.

## Как открыть

Сайт читает `data/content.enc`, поэтому двойным кликом по `index.html` он не
заработает — нужен веб-сервер:

```bash
python -m http.server 8123
```

Дальше `http://localhost:8123`. Чтобы открыть с телефона — тот же адрес, но с
IP компьютера в локальной сети (`http://192.168.x.x:8123`), телефон и компьютер
в одном вай-фае.

Оговорка про этот сервер: `http.server` не отвечает на Range-запросы, поэтому
браузер тянет каждый ролик целиком и не умеет перематывать внутри ещё не
скачанного фрагмента. На воспроизведение и автопереход это не влияет — они
перемоткой не пользуются, — но для показа лучше выложить прототип на обычный
статический хостинг, где Range поддерживается.

## Механика

**Свайп вверх и вниз — серии внутри сериала.** Серия доигрывает до конца и
следующая стартует сама, без действия зрителя: именно на этом держится метрика
досмотра 1→10. За три секунды до конца поверх видео всплывает клиффхэнгер.
Справа — точки прогресса по сериалу. Тап по экрану ставит на паузу.

**Свайп влево и вправо — переключение сериалов.** Открывается превью: постер,
жанр, синопсис, кнопка. Через три секунды бездействия превью уезжает само и
серия стартует; нажатие запускает сразу. Если сериал уже начинали, кнопка
предлагает продолжить с той серии, где остановились.

При первом открытии плеера на две секунды показывается подсказка про обе оси.
Горизонтальный свайп неочевиден, и без подсказки половина механики остаётся
ненайденной. Подсказка живёт только в памяти вкладки — каждое свежее открытие
сайта показывает её заново, чтобы телефон, на котором прототип уже гоняли при
подготовке, не показал ленту «немой».

На десктопе те же оси работают стрелками клавиатуры, пробел — пауза.

## Оффлайн

После первой загрузки service worker утаскивает всё видео в кэш, и дальше сайт
работает без сети. Это не украшение: показ идёт с телефона в переговорке, где
вай-фай может лечь, а переиграть демонстрацию нельзя.

**Перед показом:** открыть сайт заранее, дождаться в консоли
`Оффлайн-кэш готов: 40/40`, дальше можно включать авиарежим и проверять.

Service worker поднимается только на `https` или `localhost` — по `http` в
локальной сети он не зарегистрируется, и это нормально: останется обычная
загрузка по сети. Оболочка кэшируется network-first (правки кода всегда
доезжают), медиа — cache-first.

Прогрев тянет около 90 МБ. При включённой экономии трафика или на 2G он
не запускается.

## Контент

Четыре сериала по десять серий. Набор повторяет логику теста из дека:
две романтики, анимация и сказочное.

| Сериал | Жанр |
|---|---|
| Свадьба по контракту | романтика, контрактный брак |
| Три года спустя | романтика, возвращение |
| Наследница драконьего дома | историческое фэнтези, попаданка |
| Внук, которого не ждали | драма, скрытый наследник |

Названия, синопсисы и все сорок клиффхэнгеров написаны под ядро аудитории из
дека (Ж 25–45, романтика).

Набор задумывался под жанровую логику теста из дека — две романтики,
манджу-анимация и сказочное. Вертикальной анимации в открытом доступе найти
не удалось: всё, что находится по запросам про маньхуа и донхуа, оказывается
либо горизонтальным, либо живыми актёрами. Поэтому третий сериал стал
историческим фэнтези, а четвёртый — современной драмой: тексты приведены
в соответствие с тем, что реально на кадрах. Обложки и подписи проверялись
по кадрам — расхождений между жанром и картинкой не осталось.

**Видео — чужое.** Это фрагменты сторонних вертикальных сериалов из открытых
источников, взятые как референс, чтобы показать механику формата. Своего
материала на момент сборки нет, права не приобретались, коммерческого
использования не предполагается. Идентификаторы исходников записаны в каталоге
(`source.id` у каждого сериала). В разметке стоит `noindex`, чтобы прототип не
попадал в поиск.

Как только появится собственный материал, чужой заменяется подменой файлов
в `media/s1..s4/`.

Четвёртый сериал изначально был задуман русской деревенской сказкой
(«Терем на семи ветрах»), но под этот слот нашлась только мистика в восточном
антураже. Постер режется из того же видео, так что несовпадение текста и
картинки бросалось бы в глаза — сюжет переписан под доступный материал,
жанровый слот сохранён.

**Когда появятся ролики Алехина**, они встают на место фрагментов подменой
файлов в `media/s1..s4/` — код трогать не нужно.

## Устройство

Ни одного внешнего ресурса: ни шрифтов, ни библиотек, ни CDN. Иначе оффлайн
не имел бы смысла.

```
index.html            вход, витрина и плеер в одной странице
css/style.css
js/app.js             вход, витрина, состояние, оффлайн
js/player.js          обе оси навигации, автопереход, превью
data/content.enc      весь контент, зашифрованный паролем
data/content.json     он же открытым текстом — только локально, в .gitignore
sw.js                 оффлайн-кэш
media/                постеры и фрагменты
scripts/pack.mjs          шифрует каталог перед публикацией
scripts/unpack.mjs        восстанавливает плейнтекст после клонирования
scripts/fetch_media.py    добывает и режет видео
scripts/check_media.py    проверяет комплектность перед показом
scripts/find_vertical.py  ищет вертикальные сериалы на YouTube
```

После свежего клонирования, чтобы править контент:

```bash
node scripts/unpack.mjs sujet2026     # получить data/content.json
# ...правки...
node scripts/pack.mjs sujet2026       # обратно в data/content.enc
```

**Всё содержимое — в `content.json`,** плеер рендерится из него. Количество
сериалов и серий нигде не зашито: добавить пятый сериал или урезать сезон до
шести серий — правка данных, а не кода. Этот же каркас переносится в боевую
версию.

### Почему нет IntersectionObserver и requestAnimationFrame

Обе вещи напрашивались — активная серия через `IntersectionObserver`, отсчёт
превью через `requestAnimationFrame`. Обе выкинуты: они работают внутри цикла
отрисовки и молча замолкают, когда вкладка не рисует кадры. При сборке это
поймалось — лента переставала переключать серии, а превью зависало навсегда.

Сейчас активная серия считается по позиции скролла (со `scroll-snap` она
кратна высоте панели — это точный расчёт), событие `scroll` работает основным
путём, а редкий таймер подстраховывает. Отсчёт превью — `setTimeout`, полоска —
CSS-переход. Плавный скролл после запроса проверяется: если лента не тронулась
за 420 мс, доводится жёстко.

Правило простое: механика показа не должна зависеть от того, рисует ли браузер
кадры прямо сейчас.

## Подготовка видео

```bash
pip install yt-dlp imageio-ffmpeg
python scripts/fetch_media.py           # всё, чего не хватает
python scripts/fetch_media.py s3 s4     # только указанные сериалы
```

Скрипт качает каждый фрагмент отдельным коротким отрезком с тремя попытками:
на длинных отрезках соединение рвётся, и обрыв не должен уносить весь сериал.
Готовые файлы пропускаются, так что запускать можно повторно — недостающее
дотянется.
